# CoopCookingGame

**目前版本:V1.1**

雙人合作手機網頁遊戲,類似《胡鬧廚房》玩法,兩支 iPhone 透過 WebRTC 直連遊玩,不需要 App Store,不需要 Mac,遊戲進行中不需要電腦。

線上網址(GitHub Pages):**https://as5335656.github.io/CoopCookingGame/**

## 版本規則
`VERSION` 檔案跟 `index.html` 選單畫面左下角的版本號要保持一致。**每次推上 GitHub 部署新版本時,都要更新這兩個地方的版本號**,方便之後排查「兩支手機是不是玩到同一版」這類問題。

## 技術棧
- 純前端網頁:HTML5 + Canvas
- 遊戲框架:Phaser.js
- 連線:PeerJS(WebRTC 封裝),用短房號配對,配對完成後雙方直接 P2P 傳資料

## 怎麼玩(開發測試階段)
1. 在電腦上跑本機伺服器:`node dev-server.js`
2. 兩支 iPhone 連到跟電腦同一個 WiFi
3. Safari 開啟 `http://<電腦的區網IP>:3000`
4. 一支按「建立房間」拿到房號,另一支輸入房號「加入房間」

## 角色分工(第一關)
兩人共用同一個廚房場景,依場景佈局分工(不是程式碼寫死的角色類別):
- 左側:料理站(材料箱、油炸鍋、取盤、垃圾桶、工作台)
- 右側:外場(飲料機、顧客桌位),顧客主要從右側/門口進來
- **中間走道兩邊都不能穿越**,雙方各自鎖在自己的區域,只能靠出餐口交接東西

## 操作方式
- **點擊/點選地板移動**(不是搖桿),點到站點範圍內會自動走過去並互動
- 一般連線模式:手機各自只控制自己的角色
- **本機測試模式**(選單「本機測試」按鈕):不用連線,一個人在同一台裝置上同時操控 P1(點左半邊)和 P2(點右半邊),方便自己一人測試玩法

## 美術素材
背景暫時直接裁自使用者提供的參考截圖(`assets/sprites/kitchen_bg.png`),角色/物品仍用 emoji 佔位(🥔🍟🥤🐱🦊等)。
等使用者提供正式 PNG 後,只需要在 `KitchenScene.js` 把對應的圖片/emoji Text 物件換成 Phaser Image/Sprite 即可,不影響其他邏輯。
建議:透明背景、英文命名、同類型素材尺寸盡量一致。

## 已知限制
- Host(建立房間的那支手機)的瀏覽器分頁在遊戲中不能被切到背景或關閉,否則遊戲邏輯會停止(P2P 架構的取捨)
- 配對當下手機需要能連上網路(PeerJS 免費公開訊號伺服器),配對成功後遊戲資料才是純手機對手機直傳
- 目前只有 1 關,固定 3 分鐘、2 道菜色(薯條、飲料)
- 目前的背景圖是暫時從參考截圖裁出來的,角色/站點位置跟背景裡原本畫的物件不會完全對齊,等正式美術素材才會處理乾淨
